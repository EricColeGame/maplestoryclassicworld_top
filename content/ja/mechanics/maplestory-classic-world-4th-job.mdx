レベル120は、カジュアルプレイヤーと本気のプレイヤーを分ける壁であり、その向こう側で待っているのがメイプルストーリー クラシックワールドの4次転職です。あなたが積み上げてきたものすべて——クラス系統、装備、貯めたメル——は、そのクエストチェーンを終えた瞬間に何倍にも膨らみます。このガイドでは、必要条件、クエストの手順、マスタリーブックの周回、そしてあなたのメイプルストーリー クラシックワールドの4次転職キャラクターが強く感じられるか、それとも永久に遅れを取るかを決めるSPの判断について解説します。

## なぜ4次転職が真のエンドゲームの関門なのか

クラシックのルールセットには5次転職も、ハイパースキルも、Vマトリックスも、メインを支えるリンクスキル用サブキャラの軍団も存在しません。4次転職が最終職階であり、レベル200が硬い上限です。つまり、120に到達したプレイヤーは、単一のスキルツリーの中でさらに約80レベル分を使うことになります。メイプルストーリー クラシックワールドの4次転職は、通過点というより長期プロジェクトです。

計算は単純です。120以降は1レベルにつき3SPを獲得するので、200まで到達するキャラクターは約240SPを4次スキルに注ぎ込めます——そしてそれらのスキルのほとんどは20か30ポイントで上限に達します。すべてを最大化することはできません。この単一の制約こそ、ビルド計画が以前のどの職階よりもはるかに重要になる理由です。

見返りも同じくらい明確です。4次スキルはボス戦を支えるスキルであり、パーティーであなたが本当に求められる存在にするパーティバフも含まれます。120以前は、キャラクターをレベル上げしているのです。120以降は、キャラクターを構築しているのです。

| マイルストーン | レベル | クラシックのルールセットにおける意味 |
|---|---|---|
| 1次転職 | 10（魔法使いは8） | 基本的なクラスのアイデンティティと最初の攻撃スキル |
| 2次転職 | 30 | 専門分岐が解放される |
| 3次転職 | 70 | 中盤のスキル一式、最初の本格的な狩りツール |
| 4次転職 | 120 | 最終職階。エンドゲームのスキルツリーを解放 |
| レベル上限 | 200 | 消費できる4次SPはおよそ80レベル分 |

## 前提条件：レベル120、教官クエスト、英雄アイテム

関門そのものは単純です：キャラクターがレベル120で、すでに3次転職を完了している必要があります。先に進むことも、クエストを早めに貯めておくこともできません。

そこから、チェーンはあなたの転職教官を通じて進みます。オリジナルのクラシック時代のバージョンのクエストでは、2つのレアクエストアイテムを持ち帰るよう求められます：ヘロイックスターとヘロイックペンタゴンです。コミュニティの報告は一貫して、リーフレ村地域のフィールドボスであるマノンとグリフィーを入手元として指摘しています。クラシック系サーバーの中には正確な要件を調整しているところもあるので、10年前のガイドを信じるのではなく、ゲーム内のクエストログで現在のテキストを必ず確認してください。

変わっていないのは面倒さです。これらはインスタンス化された遭遇ではなくフィールドボスであり、つまりスポーンとチャンネルを他のプレイヤーと競い合うことになります。プレイヤーの経験からすると、このステップは一晩の作業ではなく複数回にわたるプロジェクトとして扱うべきです。

| 必要条件 | 詳細 | 重要な理由 |
|---|---|---|
| キャラクターレベル | 最低120 | 厳格な関門。回避策は存在しない |
| 3次転職の完了 | 完了していなければならない | そうでなければチェーンは開始しない |
| 転職教官クエスト | 自分のクラスNPCから開始 | 転職チェーンが始まる |
| ヘロイックスター | リーフレ村のフィールドボスからのレアドロップ | 多くの場合、狩りの長い方の半分 |
| ヘロイックペンタゴン | 2体目のフィールドボスからのレアドロップ | チャンネルとパーティーの助けを事前に計画する |
| インベントリの空き | 少なくとも数スロットの空き | バッグが満杯だとクエストアイテムを取り逃すことがある |

## 4次転職のステップバイステップ

以下の順序は、クラシックのチェーンが概ねどう進むかを反映しています。チェックリストとして扱い、進めながら各ステップをクエストログで確認してください。

1. **レベル120に到達する。** 保留中の3次転職クエストを先に終わらせてください。未完了のクエストが新しいチェーンを妨げることがあります。
2. **転職教官に話しかける。** 通常、クエスト通知は自動的に表示されますが、待つよりも自分からNPCに歩み寄る方が速いです。
3. **転職クエストを受諾する。** クエストテキストを注意深く読んでください——必要なアイテムはここに記載されています。
4. **クエストアイテムのためにフィールドボスを狩る。** ポーションを持参し、混雑を想定し、高レベルのフレンドにチャンネルを押さえてもらうよう頼むことも検討してください。
5. **戻ってアイテムを納品する。** 教官が転職を完了させ、あなたは正式に4次転職キャラクターになります。
6. **キーボード配置を組み直す。** 新しいスキルは未割り当ての状態で手に入り、ほとんどのプレイヤーが最初にやることは、古い筋肉記憶が間違っているためにボス戦で戸惑うことです。

| ステップ | 行動 | 注意点 |
|---|---|---|
| 1 | レベル120に到達 | チェーンを妨げる可能性のある古いクエストを片付ける |
| 2 | 転職教官を訪ねる | 狩り中はクエスト通知を見逃しやすい |
| 3 | チェーンを受諾 | ログにある正確なアイテム名をメモする |
| 4 | クエストアイテムを集める | スポーンが競合する。パーティープレイとチャンネル切り替えを使う |
| 5 | 納品して転職 | 職業名が即座に変わる |
| 6 | 新スキルを割り当てる | 次のボス戦の最中ではなく、その前にやること |

## マスタリーブック：4次スキルの隠れたコスト

ここが新規プレイヤーが過小評価する部分です。ピカピカの新しい4次スキルは、フルパワーでは手に入りません。クラシックシステムでは、そのほとんどがスキルポイント上限10という低い状態で始まり、その上限を引き上げるにはマスタリーブックを消費しなければなりません。マスタリーブック20は上限を20に、マスタリーブック30は上限を30に引き上げます。ブックは特定のスキルに紐づいており、だからこそ人気のある単一のブックの市場は厳しくなり得ます。

ブックは取引可能なので、ゲーム内で最大級のメル吸い込み口のひとつになります。コミュニティの報告では、特定のブックは実質的にレベル上げの上に重なる第二の周回だと描写されています。予算を立てるなら、自分でブックを周回して集めるか、メルを稼いで買うか、早めに決めてください。

いくつかの4次ツールはこのシステムの完全に外側にあります。状態異常を解除するヒーローズウィルのようなユーティリティスキルは、通常ブックではなくクエストで解放され、万能パーティバフのメイプルウォリアーはほぼすべてのクラスが投資したいスキルのひとつです。SPを使う前に、各スキルのツールチップでブックが必要かどうかを確認してください。

| ブックの階層 | 効果 | 主な入手元 | 備考 |
|---|---|---|---|
| ブック不要 | スキルを直接最大化できる | クエスト報酬または初期習得 | 通常はユーティリティスキル |
| マスタリーブック20 | スキル上限を10から20に引き上げる | ボスドロップ、一部のクエスト | ほとんどの4次スキルの入口 |
| マスタリーブック30 | スキル上限を20から30に引き上げる | より希少なボスドロップ | 通常は高額な買い物 |
| スキル専用ブック | 各ブックが1つのスキルを解放 | ドロップとプレイヤー市場 | クラスの人気度で価格が大きく変動 |

| 状況 | 推奨アプローチ | 理由 |
|---|---|---|
| 人気クラスをプレイしている | 主要ブックを早めに買う | サーバーが成熟するにつれて価格が上がる |
| ニッチなクラスをプレイしている | 機会を見て周回して買う | ブックの供給が薄く予測不能になり得る |
| メルが足りない | 1つのコア攻撃スキルを優先する | 最大化した1つのスキルは、中途半端な4つに勝る |
| ギルドがある | 共有ブックドロップについて尋ねる | プレイヤーの経験：ギルドは希少ブックをしばしばプールする |

## SP計画、ビルド優先度、よくある間違い

120以降は1レベルにつき3SPを獲得します。これは寛大に聞こえますが、どれだけのスキルがそのポイントを欲しがっているかに気づくまでは。信頼できる枠組みは、ダメージを最優先で資金提供し、次にパーティーへの価値、最後に快適さのスキルです。

主要な攻撃スキルは、最初に上限まで押し進めるべきものです。何千回も押すことになるスキルだからです。その後は、パーティー全体の出力を倍増させるもの、次に生存性のパッシブ、次に機動力とQoLツールを優先します。特定の問題を解決するユーティリティスキル——たとえば厄介な状態異常の除去など——は、はるかに後で最大化するとしても、早い段階で1ポイントの価値があります。

| 優先度 | 最初に資金提供するもの | 一般的なビルドの例 |
|---|---|---|
| 1 | コアのボス戦攻撃 | ブランディッシュ、ブラスト、バーサク、ハリケーン、スリートロー |
| 2 | パーティのダメージバフ | シャープアイズ、メイプルウォリアー、タイムリープ |
| 3 | 生存性のパッシブ | アキレス、ガーディアン、ビホルダー |
| 4 | 機動力とユーティリティ | ラッシュ、スモークスクリーン、ヒーローズウィル |

| 間違い | 結果 | 修正 |
|---|---|---|
| ブックを買う前にSPを使う | ポイントが低い上限の下で無駄になる | まずブックの入手可否を確認する |
| 多くのスキルにSPを分散させる | ボスコンテンツに十分な強さのものがない | 一度に1つのスキルに集中する |
| パーティバフを飛ばす | ソロ専用キャラクターになる | 全員を助けるバフに資金提供する |
| クエスト限定スキルを無視する | ブック代なしの無料ユーティリティを逃す | 転職直後にクラスクエストを終わらせる |
| 最も希少なブックを最初に買う | めったに使わないスキルに過剰支出する | 実際のローテーションに購入を合わせる |

## FAQ

### メイプルストーリー クラシックワールドで4次転職に必要なレベルは？

レベル120に到達し、3次転職を完了している必要があります。近道も、レベル要件を回避するクエストアイテムも、チェーンを早く始める方法もありません。120に到達すると、転職教官を通じて転職クエストが利用可能になります。

### クラス系統が示すものとは別の4次転職を選べますか？

いいえ。メイプルストーリー クラシックワールドの4次転職は、3次転職の分岐によって完全に決まります。クルセイダーはヒーローに、プリーストはビショップに、ハーミットはナイトロードになります。別のエンドゲームクラスが欲しいなら、120で選択を期待するのではなく、新しいキャラクターを育てる必要があります。

### スキルを最大化するのにマスタリーブックは必須ですか？

ほとんどの4次スキルについては、はい。適切なブックがなければ、スキルポイント上限は低いままで、そのスキルの最大レベルに到達できません。一部のユーティリティスキルは代わりにクエスト限定なので、何かを買う必要があると決めつける前に、各スキルの要件を注意深く読んでください。

### 転職直後に何をすべきですか？

新しいスキルをキーボードに割り当て、コア攻撃スキルのブックを買うか周回して集め、無料のユーティリティスキルを解放するクラスクエストを終わらせてください。その後、本格的なパーティーランに参加する前に、慣れたボスで新しいローテーションを試してください。コミュニティの報告によると、ほとんどのプレイヤーは新しいスキル順をリハーサルしなかったというだけの理由で、転職後初のボス戦に負けています。

公式サーバーのニュースとパッチノートについては、古いガイドに頼る前に[メイプルストーリー公式サイト](https://maplestory.nexon.net/)を確認してください。クラシック系サーバーは時折、クエスト要件とドロップテーブルを調整するからです。
